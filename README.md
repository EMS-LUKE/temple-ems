# 鹿耳門聖母廟煙火勤務系統

廟會勤務用的案件系統。空拍底圖可離線、GPS 自動帶區碼、多支手機同步。

## 一、放上 GitHub Pages

1. 在 GitHub 建一個新的 repository（例如 `temple-ems`），設為 Public。
2. 把這個資料夾裡的**所有檔案**上傳。所有檔案都在同一層，沒有子資料夾。
3. Settings → Pages → Source 選 `Deploy from a branch`，Branch 選 `main`、資料夾選 `/ (root)`。
4. 幾分鐘後網址是 `https://ems-luke.github.io/temple-ems/`。

做到這裡就能用**單機模式**：每支手機各自記錄，不會互相同步。

## 二、開啟多機同步（Firebase，免費方案）

1. 到 <https://console.firebase.google.com> 用 Google 帳號建立專案（不用開 Analytics）。
2. 左側 Build → Firestore Database → 建立資料庫，位置選 `asia-east1`（台灣），模式選「正式版」。
3. Firestore 的「規則」分頁，把內容換成 `firestore.rules` 檔案裡的內容，按發布。
4. 專案設定（齒輪）→ 一般 → 你的應用程式 → 新增「網頁」應用程式，會得到一段 `firebaseConfig = { ... }`。
5. 打開 `config.js`，把 `firebase: null` 改成 `firebase: { apiKey: "...", ... }`（整段大括號貼進去）。
6. 打開 `sw.js`，把 `VERSION` 的數字加一，兩個檔案一起上傳到 GitHub。
7. 每支手機到「統計・設定 → 同步」輸入**同一組勤務代碼**（6 碼以上英數字）。

勤務代碼等於密碼：知道代碼的人都能讀寫這一組案件。請用不好猜的代碼，每次活動可以換一組。
系統不記錄姓名、身分證號等個資，備註欄也請不要填。

## 三、每支手機出勤前要做的事（要在訊號好的地方）

1. 用 Safari（iPhone）或 Chrome（Android）打開網址，允許定位。
2. 加到主畫面（iPhone：分享 → 加入主畫面；Android：選單 → 安裝應用程式）。
3. 從主畫面打開，設定呼號、輸入勤務代碼。
4. 「統計・設定 → 下載廟區離線底圖」按一次，等它跑完。
5. 開飛航模式再打開一次，確認地圖和案件都看得到。

## 四、第一次到現場要做的事

- **校正分區**：「統計・設定 → 校正分區」，在空拍圖上依序點 A1 左前角、C1 右前角、A6 左後角。
  左右以「面向廟」為準。校正完重新下載一次離線底圖（範圍會跟著變）。
- **改區名**：預設的殿宇順序是估計的，請依實際配置修改。
- 現場的區碼標示牌要跟系統裡的一致。

## 使用

- **建案**：按「在我的位置建立案件」（用 GPS），或直接點地圖上患者的位置（殿內 GPS 不準時用這個）。
- **出勤**：案件頁按「我出勤 → 到達現場 → 後送／現場結案」，每一步自動記時間。
- **找案件**：案件詳細頁會顯示「東北方 80 公尺」這類方向距離，也可以開 Google 地圖。
- **刪除**：案件詳細頁最下方「刪除案件」，按兩次確認，全隊的畫面都會消失且無法復原，也不會出現在統計和匯出裡。誤報但想留紀錄的用「取消案件」。統計頁可一次刪除所有已取消的案件。
- **開始新活動／過去活動**：「開始新活動」在統計頁最下方的「管理員功能」裡，要輸入畫面上的 4 位數字才會執行。舊案件不會刪除，會列在「過去活動」，可以下載 CSV 或切回去。
- **處置紀錄**：到達現場後，案件卡片和詳細頁會出現「處置紀錄」，先選主訴（創傷／非創傷），再依 X、C 脊椎、C 意識（AVPU）、A、B、C 循環、D、E 的順序勾選「情況」和「處置」。GCS、瞳孔、感覺／運動功能，以及血氧、血壓、血糖、體溫都可以記錄多次並附時間，會同步給全隊並一起匯出。
- **匯出**：統計頁可複製到 Excel 或下載 CSV。

## 位置碼（用無線電傳精確位置）

每一格再切成九宮格，由廟前往廟後數：**下排 1 2 3 靠廟前，中排 4 5 6，上排 7 8 9 靠廟後，左右以面向廟為準**（跟電腦數字鍵盤的排列一樣）。
位置碼寫成 `B2-7`，唸法「B2 之 7」，範圍約 24 × 17 公尺。

- 總站在地圖上點位置或建案，畫面會顯示位置碼，照著用無線電唸。
- 隊員按地圖上的「位置碼」→ 選區、選九宮格數字 →「顯示在地圖上」，**不需要網路**。可以直接建案，或用來更改既有案件的位置。
- 地圖放大到最大會顯示每個小格的位置碼。
- 更改案件位置：案件詳細頁 →「在地圖上改位置」（點地圖或輸入位置碼），或直接改詳細頁裡的位置碼。

## 導引箭頭

- 按「我出勤」或案件詳細頁的「導引到這裡」，地圖上方出現箭頭、方向、距離，並畫出到案件的虛線。
- 手機有指南針且已允許時，箭頭指向實際方向（iPhone 第一次會詢問是否允許動作與方向）。否則箭頭以畫面上方為北，請對照地圖。
- 指南針靠近金屬、車輛、音響時會偏，箭頭和地圖不一致時以地圖為準。
- 到達後按「到達現場」，導引自動結束。

## 新案件提醒

- 收到別人新建的案件，或案件位置被更改時，畫面上方出現提醒橫幅，並發出提示音；Android 會震動，iPhone 網頁無法震動。
- 手機要解除靜音，系統要開在畫面上才會響。螢幕關閉或切到別的 App 時不會提醒。
- 提醒要靠同步才收得到，斷訊時仍以無線電為準。

## 同步狀態

右上角顯示「已同步 14:32」，或「離線・上次同步 3 分前」「待上傳 2 筆・上次同步 3 分前」。

## 限制

- GPS 戶外誤差約 5–20 公尺，殿內會更差甚至跳區。區碼和地標才是主體，GPS 是輔助。
- 斷訊時案件存在手機裡，顯示「待上傳 N 筆」，有訊號會自動補傳。斷訊期間看不到別人新建的案件，無線電仍是主要通訊。
- 兩個人同時離線修改同一筆案件，以較晚修改的為準。
- 隊友位置約每 30 秒更新一次，需要有訊號。

## 修改後的更新

改任何檔案後，把 `sw.js` 的 `VERSION` 加一再上傳。手機打開後會在背景下載整包新版，下載完自動重新載入一次。記得 `app.js` 最上面的 `APP_VERSION` 也要改成同一個版本號。「統計・設定」最下方會顯示目前版本，也有「檢查更新」按鈕可以手動更新。
